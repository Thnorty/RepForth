Animated ring for set and rest time. Always pair it with the number in the centre — the ring alone is decoration.

```jsx
<ProgressRing value={0.62} size={220} tone="rest" label="Rest 1:30 remaining">
  <StatBlock value="1:30" label="Rest" size="xl" align="center" tone="accent" />
</ProgressRing>
```

Tones: `accent` working set, `rest` amber, `done` sage.
